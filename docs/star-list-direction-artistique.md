# Références star-list pour l'identité visuelle (26 octobre 2026)

Source examinée : [dbrckk/star-list / WEB_RESOURCES.md](https://github.com/dbrckk/star-list/blob/main/WEB_RESOURCES.md).

- **Awwwards** et **Recent.design** : repères d'identité premium, typographie éditoriale, espaces blancs et photographie produit ; inspiration seulement, sans copier de templates.
- **60fps.design** : animations discrètes sur cartes, transitions rapides et respect de `prefers-reduced-motion` ; implémentation CSS locale sans abonnement.
- **21st.dev** : patterns d'interface et hiérarchie de fiches, sans importer de composants React inutiles pour le site statique.
- **Skill Issue** : catalogue de compétences à auditer, aucune dépendance installée automatiquement sans vérification de licence.

Décisions implémentées : collection multimarque principale pointant vers 15 modèles réels, cartes rehaussées avec micro-interactions, navigation entre les deux vitrines et séparation stricte des concepts de marque propre.

**À faire pour des photos réelles** : obtenir une licence écrite ou des flux images autorisés via les programmes d'affiliation/fabricants ; ne pas réutiliser sans permission les photos de montres d'Amazon ou d'autres boutiques. Les dessins CSS actuels sont des illustrations non contractuelles.
